# Forecast

A small weather app for the iPhone home screen, built as a web app (PWA).

- Forecast data: [MET Norway](https://api.met.no/) Locationforecast 2.0 (the data behind yr.no), CC BY 4.0
- Weather icons: [metno/weathericons](https://github.com/metno/weathericons) © Yr, MIT
- Place names: [OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/), © OpenStreetMap contributors

Install: open the site in Safari on iPhone → Share → Add to Home Screen.

Preview any weather animation with `?sky=<symbol_code>&wind=<m/s>`, e.g. `?sky=heavyrainandthunder&wind=12`.
